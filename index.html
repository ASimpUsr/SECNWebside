📖 简介

SimpleEmailClientNEXT 是一款基于 Electron 的桌面邮件客户端，旨在提供轻量、安全、现代化的邮件体验。 它支持多账户、IMAP/SMTP 以及 Gmail OAuth，所有数据仅保存在本地，绝不收集用户隐私。

✨ 核心功能

📧 多账户管理 同时管理多个邮箱，轻松切换
🔑 OAuth 登录 支持 Gmail（Beta），无需应用专用密码
✍️ 富文本编辑器 基于 Squire，支持加粗、链接、引用等
🌙 深色/浅色主题 自动跟随系统，夜间友好
📎 附件管理 拖拽上传，支持多种格式
🔒 本地存储 凭据加密（Windows Credential Manager），不依赖云端
📄 分页加载 自定义每页邮件数量，高效浏览
🔄 自动更新（规划中） 1.2.1 版本将支持增量更新

🚀 快速开始

📦 下载安装包

从 Releases 页面 下载对应平台的安装包（Windows 建议 NSIS 安装包，也提供便携版）。

🔧 开发者模式

克隆仓库并运行：

$ git clone https://github.com/ASimpUsr/SimpleEmailClientNEXT.git
$ cd SimpleEmailClientNEXT
$ npm install
$ npm run dev

📤 打包

$ npm run build

产物位于 dist/ 目录下。

🔐 隐私与安全

我们绝不收集您的任何数据。所有邮件、令牌、设置均存储在本地。 您可以通过 隐私政策 了解详情。
